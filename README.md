# تعريب Megabonk | Megabonk Arabic

<div dir="rtl">

تعريب كامل لـ Megabonk (نسخة ستيم 1.0.69): القوائم والإعدادات والشخصيات والأسلحة والكتب والأدوات والخرائط والمهام والإنجازات والمتجر وحوارات الشخصيات. العربية تاخذ مكان الإنجليزية.

التعريب ما يحتوي أي ملف من ملفات اللعبة. البرنامج يعدّل ملفات اللعبة اللي عندك أنت ويحفظ نسخة من الأصلية. ومعه BepInEx 6 وإضافة صغيرة ترتب النص العربي في وصف الخريطة والأهداف الطويلة.

## اللي تحتاجه

1. نسخة ستيم من Megabonk، **الإصدار 1.0.69** (رقم البناء 21750826).
2. مجلد اللعبة بدون BepInEx أو مودات ثانية.
3. إنترنت في أول تشغيل بعد التثبيت (BepInEx ينزّل ملفات Unity مرة وحدة).

## الخطوات

1. سكّر اللعبة.
2. حمّل `Megabonk-Arabic-1.0.zip` من [Releases](../../releases/latest) وفك ضغطه.
3. افتح `MegabonkArabic.exe`. إذا طلعت رسالة "Windows protected your PC" اضغط More info ثم Run anyway (البرنامج مو موقّع رقميًا).
4. اختر مجلد اللعبة (`steamapps\common\Megabonk`، البرنامج يلقاه بنفسه غالبًا) واضغط «ثبّت التعريب».
5. شغّل اللعبة واترك اللغة على **English**. أول تشغيل ياخذ دقيقة أو دقيقتين قبل ما تطلع الشاشة الأولى، لا تسكّرها.

## الإزالة
افتح `MegabonkArabic.exe` واضغط «أزل التعريب». ترجع ملفاتك الأصلية من النسخة الاحتياطية. بعدها تقدر تحذف مجلدي `BepInEx` و`dotnet` من مجلد اللعبة.

## ملاحظات
- إذا حدّثت ستيم اللعبة، ملفات التعريب ترجع إنجليزي. ثبّت إصدار التعريب اللي يناسب التحديث.
- باقي بالإنجليزي: كلمات الندرة على البطاقات (Common وNew)، كلمتي Character وWeapon في بعض أسطر المهام، وأسماء اللاعبين.
- الخط: Noto Sans Arabic مع Noto Sans (رخصة SIL Open Font License 1.1). BepInEx برخصة LGPL 2.1.
- كود البرنامج موجود في مجلد [`app`](app) في هذي الصفحة، وتقدر تبنيه بنفسك بـ `build.cmd`.

## English

Complete Arabic translation of Megabonk (Steam version 1.0.69): menus, settings, characters, weapons, tomes, items,
maps, quests, achievements, shop and character dialogue. Arabic takes the place of English.

No game file is included. The program patches the game files of your own copy and keeps a backup of the originals.
It comes with BepInEx 6 and a small plugin that orders Arabic text in the map description and long objectives.

### What you need

1. The Steam version of Megabonk, **version 1.0.69** (build 21750826).
2. A game folder without BepInEx or other mods.
3. Internet on the first start after installing (BepInEx downloads Unity files once).

### Steps

1. Close the game.
2. Download `Megabonk-Arabic-1.0.zip` from [Releases](../../releases/latest) and extract it.
3. Open `MegabonkArabic.exe`. If "Windows protected your PC" appears, click More info, then Run anyway (the program is
   not digitally signed).
4. Choose the game folder (`steamapps\common\Megabonk`; the program usually finds it) and click "Install".
5. Start the game with the language set to **English**. The first start takes a minute or two before the first screen
   shows; do not close it.

### Uninstall
Open `MegabonkArabic.exe` and click "Uninstall". Your original files come back from the backup. Then you can delete
the `BepInEx` and `dotnet` folders from the game folder.

### Notes
- If Steam updates the game, its files go back to English. Install the translation version made for that update.
- Still in English: rarity words on cards (Common, New), the words Character and Weapon in some quest lines, and
  player names.
- Font: Noto Sans Arabic with Noto Sans (SIL Open Font License 1.1). BepInEx is LGPL 2.1.
- The program's source is in the [`app`](app) folder; you can build it yourself with `build.cmd`.
